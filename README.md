# Hospital HCAHPS Patient Satisfaction Data Analysis

## 📌 Project Overview
This project presents an end-to-end data analytics solution using **SQL Server (T-SQL)** and **Power BI** to evaluate, clean, and visualize the Hospital Consumer Assessment of Healthcare Providers and Systems (**HCAHPS**) survey dataset. The analysis transforms raw survey responses into executive KPIs and visual insights on hospital ratings, patient response rates, and regional healthcare performance.

---

## 🛠️ Tech Stack & Tools
- **Database Management:** Microsoft SQL Server / SQL Server Management Studio (SSMS)
- **Data Transformation:** T-SQL (Views, Data Type Casting, Data Cleaning)
- **Business Intelligence & Visualization:** Power BI Desktop
- **Data Source:** HCAHPS Hospital Survey Dataset (`.zip`)
